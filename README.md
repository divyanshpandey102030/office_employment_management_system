# Employee Management System

A web-based **Employee Management System** developed using **Python, SQL, HTML, CSS, and JavaScript**. The project allows users to manage employee information and perform complete **CRUD (Create, Read, Update, Delete) operations**.

## 🚀 Features

* Add new employees
* View employee details
* Update employee information
* Delete employee records
* Store and manage employee data using SQL
* Simple and responsive web interface
* Backend logic developed using Python
* Frontend developed using HTML, CSS, and JavaScript

## 🛠️ Technologies Used

### Backend

* Python
* SQL

### Frontend

* HTML5
* CSS3
* JavaScript

### Database

* SQL Database

## 📌 CRUD Operations

The application supports the following operations:

* **Create** – Add a new employee
* **Read** – View employee records
* **Update** – Modify existing employee information
* **Delete** – Remove employee records

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone <your-repository-url>
```

2. Open the project folder:

```bash
cd Employee-Management-System
```

3. Configure the SQL database and update the database connection details in the Python backend.

4. Run the Python backend.

5. Open the frontend in your browser.

## 💡 Project Objective

The main objective of this project is to provide a simple system for managing employee records digitally. It demonstrates how a **Python backend, SQL database, and web frontend** can work together to perform employee data management and CRUD operations.
